根据保龄球每次击倒的球瓶数，将数字记录依次映射为指定符号并拼接输出。题目逻辑属于基础分支模拟，关键在于输出格式的连贯拼接与大小写细节。

<!-- more -->

## 题目与关键约束

高桥投掷了 $N$ 次保龄球，第 $i$ 次击倒的球瓶数为 $A_i$。需要在记分表上记录每次投掷的结果，规则如下：
- 若击倒 10 个球瓶，记为大写字母 `X`；
- 若击倒 0 个球瓶（全空），记为减号 `-`；
- 其余情况（击倒 1 到 9 个球瓶），记为对应的数字字符（`1` 到 `9`）。

输出一个长度为 $N$ 的连续字符串，按先后顺序展示每次投掷的记录。

**关键约束**：
- $1 \le N \le 100$
- $0 \le A_i \le 10$
- 所有输入均为整数。

**示例**：
输入：
```text
5
7 10 3 9 10
```
输出：
```text
7X39X
```

## 思路与推导

本题为单向线性的条件分支映射问题。对于序列中的每一个击倒数 $A_i$，对应输出仅有三种确定的互斥分支：
1. $A_i = 10 \implies$ 映射为 `'X'`
2. $A_i = 0 \implies$ 映射为 `'-'`
3. $1 \le A_i \le 9 \implies$ 映射为对应的数字字符 `str(A_i)`

在具体实现上有两种常见方式：
- **流式输出**：遍历时使用 `print(ch, end='')`，将默认换行符替换为空字符串，直接逐字符输出到标准输出；循环结束后打印换行。
- **列表收集与拼接**：维护一个空列表 `ans`，每次将映射后的单个字符追加到列表中，遍历结束后使用 `''.join(ans)` 一次性拼接并输出。

相比于在循环内频繁调用带 `end=''` 的 I/O，使用列表收集后再通过 `''.join()` 拼接更符合 Pythonic 风格，也方便对结果字符串进行统一检查和调试。

由于 $N \le 100$，时间复杂度为 $O(N)$，额外空间为 $O(N)$，性能开销极低。

## 代码与复杂度

```python
def main():
    n = int(input())
    a = list(map(int, input().split()))

    ans = []
    for x in a:
        if x == 10:
            ans.append('X')
        elif x == 0:
            ans.append('-')
        else:
            ans.append(str(x))

    print(''.join(ans))

if __name__ == '__main__':
    main()
```

- **时间复杂度**：$O(N)$。遍历长度为 $N$ 的列表进行常数次条件判断，最后的字符串拼接时间为 $O(N)$，总运行时间与 $N$ 成线性关系。
- **空间复杂度**：$O(N)$。输入列表占用 $O(N)$ 空间，输出字符列表 `ans` 及拼接后的字符串各占用 $O(N)$ 辅助空间。

## 本次复盘

在初次尝试与代码实现时，注意到了以下几个细微卡点：

1. **默认换行与题目要求的单行连续输出**：
   - *原想法*：在 `for` 循环内部直接使用 `print(...)` 输出每次投掷的符号。
   - *原因与反例*：Python 的 `print()` 函数默认在结尾追加换行符 `\n`，导致原本期望的 `"7X39X"` 会被输出为 5 行单独的字符，不符合题意要求的“长度为 $N$ 的连续字符串”。
   - *修正*：要么显式传入参数 `end=''` 抑制换行，要么更推荐将各个字符收集至列表后统一通过 `''.join()` 输出。

2. **字符大小写陷阱**：
   - *原想法*：击倒 10 个球瓶时打印小写 `'x'`。
   - *原因与反例*：保龄球全中（Strike）的通用缩写以及样例输出均为大写字母 `'X'`（如样例 `7X39X`），写成小写会导致评测 Wrong Answer。
   - *修正*：对标样例输出与题面定义，确认符号为大写 `'X'`。

3. **循环迭代变量名覆盖外层变量**：
   - *原想法*：写成 `for n in a:`。
   - *原因与影响*：虽然本题在后续逻辑中未再次使用代表数组长度的 `n`，但迭代变量使用 `n` 会覆盖掉已读取的整数变量，破坏代码可读性且在后续扩展时容易引发隐蔽的引用错误。
   - *修正*：循环变量应选用语义明确的名称（如 `x`、`val` 或 `pins`）。
