在给定的婚礼现场二维座位网格中，统计未入座的空位数量。题目属于基础网格遍历与字符匹配问题，核心在于二维下标的清晰遍历或利用语言特性进行行内计数。

<!-- more -->

## 题目与关键约束

高桥正在查看婚礼现场的座位表。座位按 $H$ 行 $W$ 列排列，由 $H$ 个长度为 $W$ 的字符串 $S_1, S_2, \dots, S_H$ 表示：
- 字符串 $S_i$ 的第 $j$ 个字符代表从上到下第 $i$ 行、从左到右第 $j$ 列的座位；
- 字符 `o` 表示该座位已有人入座；
- 字符 `.` 表示该座位是空座。

求整个会场中空座的总数量。

**关键约束**：
- $1 \le H \le 10$
- $1 \le W \le 10$
- 每个字符串 $S_i$ 长度恰好为 $W$，且仅包含字符 `o` 与 `.`。

**示例**：
输入：
```text
2 3
o..
ooo
```
输出：
```text
2
```
解释：第一行有 2 个空座（`o..`），第二行没有空座（`ooo`），总共 2 个空座。

## 思路与推导

婚礼场地的座位表在逻辑上对应一个 $H \times W$ 的二维字符矩阵。每个座位的状态相互独立，题目要求统计整个矩阵中特定字符 `'.'` 的出现频次。

### 1. 经典基石：嵌套双重循环
最直接、也是最具普适性的解法是坐标遍历：
- 外层循环遍历行索引 $i \in [0, H-1]$；
- 内层循环遍历列索引 $j \in [0, W-1]$；
- 检查当前元素 `grid[i][j]` 是否等于 `'.'`，若成立则累加器自增 1。

这种写法不依赖任何特定语言的高级内置库，是所有图论与矩阵模拟算法的逻辑基础。

### 2. Pythonic 优化：行内计数与生成式
在 Python 中，每一行字符串都是一个独立的可迭代序列，且字符串原生内置了高效的 `.count()` 方法：
- 单层循环累加：遍历每一行 `row`，执行 `ans += row.count('.')`；
- 一行生成式：`ans = sum(row.count('.') for row in grid)`。

由于数据规模 $H, W \le 10$，网格内最多仅有 100 个元素，两种实现在运行效率上均在毫秒级内瞬间完成，选用双重循环更显扎实，选用 `.count()` 则代码更紧凑。

## 代码与复杂度

以下为本次练习中独立编写的标准双重循环解法：

```python
def main():
    # 输入读取
    H, W = map(int, input().split())
    grid = [input().strip() for _ in range(H)]

    ans = 0
    # 二维网格遍历统计
    for i in range(H):
        for j in range(W):
            if grid[i][j] == '.':
                ans += 1

    # 结果输出
    print(ans)

if __name__ == '__main__':
    main()
```

- **时间复杂度**：$O(H \times W)$。需要恰好访问网格中的每一个格子一次，当 $H, W \le 10$ 时，最大比较次数仅为 100 次，属于常数级别的高效运行。
- **空间复杂度**：$O(H \times W)$。存储输入的 $H$ 个长度为 $W$ 的字符串需要 $O(H \times W)$ 的存储空间。

## 本次复盘

本次练习过程流畅，在搭建好标准 I/O 结构后，独立完成了核心遍历与判断逻辑：

1. **零基索引与矩阵维度的对应**：
   - 习惯使用 `range(H)` 与 `range(W)` 进行行列控制，无需对题目中给出的 1-based 描述做繁琐的偏置转换，自然对应 Python 列表的 `[0, H-1]` 下标范围。
2. **输入去噪防御**：
   - 使用 `input().strip()` 读取每一行座位状态是一个良好的习惯，能有效防止终端或重定向输入中残留的 `\r` 等空白符影响字符串长度与字符比较。
3. **从过程式思维向内建 API 的拓展**：
   - 双重循环清晰展示了矩阵遍历的底层本质；在掌握基础语法后，可进一步联想并运用 Python 的 `str.count()` 与生成式求和，在后续类似统计题中提升代码编写速度。
