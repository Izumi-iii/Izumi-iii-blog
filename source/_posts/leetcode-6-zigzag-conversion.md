## 题目与关键约束

- **平台与题号**：LeetCode [6. Z 字形变换](https://leetcode.cn/problems/zigzag-conversion/)
- **输入输出**：给定一个字符串 `s` 和一个正整数 `numRows`，要求按照 Z 字形排列字符后，逐行从左向右读取并输出新的字符串。
- **关键约束**：$1 \le s.\text{length} \le 1000$，$1 \le \text{numRows} \le 1000$。字符串包含大小写英文字母、逗号与句点。

以 `s = "PAYPALISHIRING"`, `numRows = 3` 为例，Z 字排列如下：

```text
P   A   H   N
A P L S I I G
Y   I   R
```

逐行读取后的结果为 `"PAHNAPLSIIGYIR"`。

## 思路与推导

面对本题，最先观察到的结构特点是**边界特判**与**周期性**：
1. **边界特判**：若 $\text{numRows} = 1$ 或者 $\text{numRows} \ge \text{len}(s)$，字符根本无需或无法折返，直接返回原字符串 `s` 即可。这一步既是性能剪枝，也是避免后续下标越界的核心防御。
2. **周期性观察**：以 $\text{numRows} = 3$ 为例，每 4 个字符为一个完整来回；推广至任意 $\text{numRows}$，一个周期的长度均为 $T = 2 \times \text{numRows} - 2$。

从求职面试的角度来看，解决这道题主要有两种策略：
- **数学跳步法**：依据周期 $T$ 推导每个字符在各行中的下标通项公式，直接提取字符构造结果。其优势在于将除输出外的辅助空间压缩至 $O(1)$，但缺点是在面试高压下容易出现 `off-by-one`（差一错误）或边界越界。
- **行指针模拟法**：准备 `numRows` 个行缓冲区，直接模拟一支“笔”在 $0$ 到 $\text{numRows} - 1$ 行之间上下穿梭。遍历每个字符追加至当前行，触碰上下边界即刻掉头。

在面试场景中，推荐优先编写**行指针模拟法**，不仅逻辑清晰、鲁棒性极高，而且时间复杂度已达到最优的 $O(N)$。

### 模拟法的状态机推导

行指针在 $0$ 到 $\text{numRows}-1$ 之间来回振荡，其状态变化仅取决于当前所在行：
- 设定当前行号 `curRow = 0`，初始方向为向下（`goingDown = True`）。
- 准备一个包含 `numRows` 个空字符串的列表 `rows`。
- 对于字符串中的每个字符 `ch`：
  1. 先将 `ch` 追加至当前行 `rows[curRow]`。
  2. 根据当前方向更新 `curRow`：若向下则 `curRow += 1`，反之 `curRow -= 1`。
  3. 检查下一步是否到达了极值边界：若 `curRow == 0` 或 `curRow == numRows - 1`，说明触顶或触底，将方向标志反转（`goingDown = not goingDown`）。
- 最终只需使用 `"".join(rows)` 将各行拼接输出。

## 代码与复杂度

```python
class Solution:
    def convert(self, s: str, numRows: int) -> str:
        # 边界特判：行数为 1 或行数大于等于字符串长度时，直接返回原字符串
        if numRows == 1 or numRows >= len(s):
            return s

        rows = ["" for _ in range(numRows)]
        curRow = 0
        goingDown = True

        for ch in s:
            rows[curRow] += ch
            # 按当前方向更新行指针
            if goingDown:
                curRow += 1
            else:
                curRow -= 1

            # 到达顶层或底层时掉头
            if curRow == 0 or curRow == numRows - 1:
                goingDown = not goingDown

        return "".join(rows)
```

- **时间复杂度**：$O(N)$，其中 $N$ 为字符串 `s` 的长度。每个字符仅被遍历一次，最后的列表合并耗时 $O(N)$。
- **空间复杂度**：$O(N)$。使用了长度为 `numRows` 的列表 `rows` 保存各行字符，总字符数等于 $N$；返回值所占空间同为 $O(N)$。

## 本次复盘

1. **原想法**：一开始试图通过“每遍历到第 $kn$ 个字符时掉头”来控制转向。
   - **原因**：将周期的全局数学计数与局部的空间移动混淆了。按字符计数容易陷入复杂的除法与余数计算。
   - **修正**：转向的本质是空间边界约束而非计数约束。只需观察行指针自身：一旦到达第 $0$ 行或第 $\text{numRows}-1$ 行，物理上无法继续前行，必须立即掉头。
2. **原想法**：在循环体内先移动 `curRow`，再将字符存入行中。
   - **反例**：若 `curRow` 初始为 $0$，一进循环先加 $1$ 变成第 $1$ 行，第 $0$ 行就会丢失首个字符。
   - **修正**：坚持“先写入当前格、再推算下一格”的顺序，确保第 $0$ 个字符稳妥落入第 $0$ 行。
3. **原想法**：将每行字符收集为嵌套列表，并用列表累加输出结果。
   - **原因**：混淆了列表追加与字符串拼接，且未留意题目要求返回 `str`。
   - **修正**：在 Python 中，行缓冲直接使用字符串即可，最后通过 `"".join(rows)` 一次性合并，简洁且避免额外的内存分配。

**下次识别信号**：遇到“折返”、“蛇形”、“Z 字”等在固定区间内来回摆动的几何轨迹题，优先使用行指针配合布尔方向标志进行边界反转模拟，切忌在循环内推算复杂的全局计数值。
