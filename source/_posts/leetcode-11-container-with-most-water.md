给定一组竖线高度，选择两条线作为容器边界，使它们与 x 轴围成的面积最大。面积由较短边和两线间距共同决定；双指针从两端向中间收缩，每次移动较短的一边，在 O(n) 时间内找出最大面积。

## 题目与关键约束

LeetCode 11「盛最多水的容器」给定数组 `height`，下标代表竖线的位置，元素代表竖线高度。选取两个不同下标 `left`、`right`，容器面积为：

```text
min(height[left], height[right]) * (right - left)
```

水位受较短的那条线限制，宽度是下标差。目标是在所有线对中找到最大面积。练习中使用 Python，用户反馈修正后的方案已通过平台。

## 思路与推导

最直接的想法是枚举所有线对，计算面积并取最大值，时间复杂度为 O(n²)。当数组较长时，可以用双指针缩减搜索。

令 `left = 0`、`right = n - 1`，此时两条线之间的宽度最大。每轮计算当前面积，然后移动较短的一边。

为什么移动短边？假设左边较短，当前面积受左边高度限制。若固定左边、只把右边向内移动，宽度变小，而新的右边高度即使更高，水位仍不超过原来的左边高度，因此面积不可能变大。要获得更大面积，只能尝试换掉较短边，寻找更高的线。右边较短时同理；两边相等时移动任意一侧都可以。

这个过程不会漏掉最优解：若最优容器的一条边是当前较短边，那么当它被移动舍弃时，另一条边还在当前区间内，之后只会形成更窄的容器，且高度上限不超过这条已固定的边，面积无法超过当前选择。于是每次都能安全地丢弃短边所在的端点。

循环持续到两指针相遇。每个端点最多移动一次，因此总时间为 O(n)，额外空间为 O(1)。

## 代码与复杂度

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        left = 0
        right = len(height) - 1
        max_area = 0

        while left < right:
            area = min(height[left], height[right]) * (right - left)
            max_area = max(max_area, area)

            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return max_area
```

时间复杂度为 O(n)，其中 n 是数组长度；额外空间复杂度为 O(1)。练习对话中用户反馈“通过”，因此记录为平台已通过；此处未另行执行本地测试。

## 本次复盘

原代码正确写出了面积公式，也知道要移动较短边，但把指针的方向写反了：右指针用了 `right += 1`，左指针用了 `left -= 1`，会走出数组范围。修正后，左指针向右移动（`left += 1`），右指针向左移动（`right -= 1`）。

另一个容易忽略的点是循环边界。使用 `left < right`，确保两条边来自不同位置；相遇时宽度为零，无需再计算。下次写双指针时，可以分别检查每个指针“从哪边开始、朝哪个方向收缩”，并验证移动后仍位于有效范围。
