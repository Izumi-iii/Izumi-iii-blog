## 题目与关键约束

- **输入输出**：采用标准输入输出。第一行给出整数 $K$，第二行给出仅由大写英文字母组成的字符串 $S$。要求将 $S$ 中的每个字母按字母表顺序向后移动 $K$ 位（`Z` 之后回绕到 `A`），在一行中输出加密后的字符串。
- **关键约束**：
  - $1 \le |S| \le 100$，且 $S$ 仅包含大写英文字母 `'A'` 到 `'Z'`；
  - $0 \le K \le 100$，$K$ 为整数；
  - 移位步数 $K$ 可能超过字母表长度 26（最大到 100），甚至可能为 0，必须支持循环回绕与零移位。

以样例 1 为例，输入 `K = 3`、`S = "ABC"`，每个字母顺次后移 3 位得到 `"DEF"`；输入 `K = 1`、`S = "Z"` 时，`Z` 向后移动 1 位回绕到 `A`，输出 `"A"`。

## 思路与推导

本题本质上是经典的**凯撒密码（Caesar Cipher）**加密模拟。每个字符的变换相互独立，只需把单个大写字母在循环字母表上的移动规律写清楚，再对整串逐字符应用即可。

### 1. 相对偏移映射与循环取模

如果直接对字符本身做加法，不仅在超出 `'Z'` 后会落到非字母字符上，也没法自然完成从 `'Z'` 到 `'A'` 的回绕。更稳妥的做法是先把 26 个大写字母映射到 $0 \sim 25$ 的整数区间：

1. **归零映射**：利用 ASCII 编码连续的特性，用 `ord(ch) - ord('A')` 把 `'A' ~ 'Z'` 一一对应到 `0 ~ 25`（例如 `'A'` 对应 `0`，`'Y'` 对应 `24`，`'Z'` 对应 `25`）。
2. **循环移位**：加上移位量 $K$ 后对 26 取模，即 `(ord(ch) - ord('A') + K) % 26`。由于字母表每移动 26 位就回到自身，无论 $K = 0$ 还是 $K = 100$，取模结果都会严格落在 `0 ~ 25` 之间：
   - 对题面示例 `ch = 'Y'`、$K = 3$：`24 + 3 = 27`，`27 % 26 = 1`，对应 `'B'`；
   - 对样例 2 `ch = 'Z'`、$K = 1$：`25 + 1 = 26`，`26 % 26 = 0`，对应 `'A'`；
   - 当 $K = 0$ 时，`(x + 0) % 26 = x`，自动保持原字符不变，无需单独分支特判。
3. **还原字符**：把计算出的新偏移加回 `ord('A')`，再用 `chr(...)` 转回对应的大写英文字母。

### 2. 预先化简移位量

在进入字符遍历前，可以先令 `k = int(input()) % 26`。虽然每个字符内部也会做 `% 26`，提前对 `K` 取模能保证后续偏移量始终在 `0 ~ 25` 之间，语义也更直观。

## 代码与复杂度

以下为修正后的最终可提交 Python 代码（已根据题面约束和样例完成静态逻辑核对，尚未在评测平台实际提交验证）：

```python
k = int(input()) % 26
s = input().strip()

ans = ''.join(chr(ord('A') + (ord(ch) - ord('A') + k) % 26) for ch in s)
print(ans)
```

- **时间复杂度**：$O(N)$，其中 $N = |S|$ 为字符串长度。预处理 `k` 为 $O(1)$，随后只需遍历一次字符串，对每个字符执行常数次算术与编码转换操作，再拼接为结果字符串。
- **空间复杂度**：除输入字符串外，构造输出字符串需要 $O(N)$ 的输出空间（生成器表达式本身仅占用 $O(1)$ 额外辅助空间，最终 `''.join(...)` 生成长度为 $N$ 的结果串）。

## 本次复盘

在本次练习中，最初提交的草稿已经想到了 `k = k % 26` 和逐字符遍历的框架，但实际运行时暴露出 4 个典型的 Python 语言与标准输入输出细节问题：

1. **标准输入未做类型转换**
   - **原写法**：`k = input()`，随后直接比较 `k == 0` 并计算 `k % 26`。
   - **原因与修正**：`input()` 读入的永远是字符串 `str`，字符串对整数取模会触发 `TypeError`，与整数 `0` 比较也恒为 `False`。应改为 `k = int(input())`。
2. **脚本顶层误用 `return`**
   - **原写法**：在没有定义函数的情况下直接写 `return s`。
   - **原因与修正**：`return` 只能出现在函数体内，顶层使用会直接触发 `SyntaxError`；同时标准输入输出题（ACM/AtCoder 模式）需要通过 `print(...)` 打印结果，而非返回值。
3. **字符直接与整数相加且缺少回绕**
   - **原写法**：`ch = ch + k`。
   - **原因与修正**：Python 中单个字符本质上仍是长度为 1 的 `str`，不能像 C/C++ 那样直接参与整数算术运算，否则会报 `TypeError`；即便转成编码值后，如果只做加法而不先减 `ord('A')` 再 `% 26`，遇到 `'Y'`、`'Z'` 时也无法正确回绕到 `'A'` 开头。
4. **忽略字符串不可变性与循环变量重绑定**
   - **原写法**：在 `for ch in s:` 中修改 `ch`，最后输出原字符串 `s`。
   - **原因与修正**：Python 字符串是不可变对象（immutable），且 `ch` 只是每次迭代新绑定的局部变量，改写 `ch` 完全不会影响原串 `s`。需要把转换后的字符收集到列表或生成器中，最后用 `''.join(...)` 生成新字符串。
