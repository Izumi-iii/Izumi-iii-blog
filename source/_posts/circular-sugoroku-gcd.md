在长度为 $N$ 的环形棋盘上，从起点 0 出发，每次可按任意次数选择顺时针跳跃 $A_i$ 步。利用模运算的循环群性质与数论中的裴蜀定理，将可达性问题转化为最大公约数的整除性判定。

<!-- more -->

## 题目与关键约束

高桥在一个由 $N$ 个格子围成的圆环上玩电子双六游戏。格子按顺时针方向依次编号为 $0, 1, \dots, N - 1$。
- **初始位置**：棋子初始位于 $0$ 号格子；
- **操作规则**：游戏机共有 $M$ 种按钮，按下第 $i$ 种按钮可使棋子沿顺时针方向前进 $A_i$ 格，即当前位置从 $x$ 移动到 $(x + A_i) \bmod N$；
- **操作次数**：每种按钮可按任意次（包括 0 次），顺序任意；
- **目标**：判断能否最终停在目标格子 $G$。若能输出 `Yes`，否则输出 `No`。

**关键约束**：
- $2 \le N \le 10^9$
- $1 \le M \le 10^6$
- $0 \le G \le N - 1$
- $1 \le A_i \le 10^9 \quad (1 \le i \le M)$
- 所有输入均为整数。

**示例**：
输入：
```text
6 2 4
2 3
```
输出：
```text
Yes
```
解释：棋盘周长为 6，按下前进 2 格的按钮两次，走法为 $0 \to 2 \to 4$，成功到达 $G = 4$。

## 思路与推导

### 1. 从游戏规则到同余方程
设第 $i$ 种按钮按下的次数为非负整数 $c_i \ge 0$。棋子从 0 出发，最终到达的位置为：
$$
\left( \sum_{i=1}^M c_i A_i \right) \bmod N
$$
能否到达目标 $G$，等价于是否存在非负整数序列 $c_1, c_2, \dots, c_M \ge 0$，使得：
$$
\sum_{i=1}^M c_i A_i \equiv G \pmod N
$$
展开同余式，即存在整数 $k \in \mathbb{Z}$，满足：
$$
\sum_{i=1}^M c_i A_i - k N = G
$$

### 2. 消除“非负次数”与“只能前进”的限制
直觉上可能会担心：题目规定只能“顺时针前进”，即 $c_i \ge 0$，是否意味着我们无法自由进行逆向抵消？
**答案是否定的，模 $N$ 的环形结构自动消除了正负限制。**
在长度为 $N$ 的环上，顺时针前进一步等价于逆时针退回 $N-1$ 步；反之，若我们需要“后退” $A_i$ 格（即系数为 $-1$），可以通过顺时针绕环前进 $N - 1$ 次来实现：
$$
-A_i \equiv (N - 1) A_i \pmod N
$$
因为 $N - 1 > 0$，所以任何含有负整数系数的线性组合，都可以通过加上足够多轮完整的周长 $N$，等价转换为全部系数均为正整数的按键方案。
因此，$c_i$ 的取值范围可以完全放宽至全体整数 $\mathbb{Z}$。

### 3. 裴蜀定理（Bézout's identity）判定
上述方程本质上是一个多元一次不定方程：
$$
c_1 A_1 + c_2 A_2 + \dots + c_M A_M + k' N = G \quad (k' = -k \in \mathbb{Z})
$$
根据数论中的**裴蜀定理**，整数集合 $\{A_1, A_2, \dots, A_M, N\}$ 的所有整系数线性组合所能生成的数集，恰好是它们最大公约数的倍密集：
$$
d = \gcd(A_1, A_2, \dots, A_M, N)
$$
棋子所能到达的所有位置集合，即为模 $N$ 剩余类中所有 $d$ 的倍数：
$$
\{ 0, d, 2d, \dots, N - d \}
$$
因此，目标格子 $G$ 可达的充分必要条件是：
$$
G \equiv 0 \pmod d \iff d \mid G
$$

### 4. 算法与早停优化
- 初始化公约数 $d = N$；
- 依次遍历每个按键步长 $A_i$，更新 $d = \gcd(d, A_i)$；
- **早停机制**：由于最大公约数的最小可能值为 1，一旦在遍历过程中发现 $d = 1$，说明所有格子均可到达，可立即跳出循环，无需继续遍历后续的数；
- 最终只需检查 `G % d == 0` 是否成立。

## 代码与复杂度

```python
import sys
from math import gcd

def main():
    # 大规模数据快速读取
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    N = int(input_data[0])
    M = int(input_data[1])
    G = int(input_data[2])
    
    # 初始将周长 N 纳入公约数计算
    d = N
    for i in range(3, 3 + M):
        d = gcd(d, int(input_data[i]))
        # 早停优化：若公约数已缩减至 1，则所有格子均可达
        if d == 1:
            break
            
    if G % d == 0:
        print("Yes")
    else:
        print("No")

if __name__ == '__main__':
    main()
```

- **时间复杂度**：$O(M + \log N)$。
  - 欧几里得算法每次求公约数的时间为对数级别；而每次 $d$ 发生严格减小时，其数值至少折半，故在整个序列中 $d$ 最多严格减小 $O(\log N)$ 次。
  - 对于未使 $d$ 减小的其余元素，单次取模运算为 $O(1)$。配合 $d = 1$ 的早停机制，处理 $M = 10^6$ 级数据总耗时在 0.2 秒左右，远低于时限。
- **空间复杂度**：$O(M)$。`sys.stdin.read().split()` 将输入完整加载至内存列表中。若使用流式生成器逐项读取，可进一步降至 $O(1)$ 辅助空间。

## 本次复盘

1. **环形结构的代数本质**：
   - *原困惑*：题目强调“只能按键前进 $A_i$ 格”，容易误以为需要借助背包 DP 或图上最短路/可达性搜索（如 BFS）。
   - *突破点*：观察到 $N \le 10^9$ 且存在取模环，绕圈一整周等价于恒等变换。借助模运算，前进一步与倒退 $N-1$ 步完全等效，从而破除了“只能正向走”的限制，直接将图遍历问题化简为纯粹的数论线性同余方程。
2. **海量输入下的 I/O 效率**：
   - 本题中 $M \le 10^6$，若使用普通的单行 `input()` 甚至循环读取，在 Python 中可能会因为 I/O 频繁切换而逼近时限。采用 `sys.stdin.read().split()` 一次性缓冲读取，是应对百万级输入规模的标准性能保障。
3. **早停（Early Stopping）剪枝**：
   - 互质情况在随机数据或包含奇偶组合时非常普遍，加入 `if d == 1: break` 能够大幅减少无意义的 GCD 计算，将最坏情况的耗时进一步压缩。
