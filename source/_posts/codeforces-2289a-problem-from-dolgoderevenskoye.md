## 题目与关键约束

- **平台与题号**：Codeforces [2289A. Problem from Dolgoderevenskoye](https://codeforces.com/problemset/problem/2289/A)
- **输入输出**：给定一个正整数 $x$，初始时桌面上有一组卡片，包含 $x$ 的所有正因数（每个正因数对应一张卡片，包含 $1$ 和 $x$ 本身）。两名玩家（Artem 先手）轮流从集合中拿走一张卡片。第一回合 Artem 可拿走任意卡片，后续每个回合玩家拿走的卡片数字奇偶性必须与上一回合相反。无法合法操作的玩家判负。判断双方均采取最优策略时，先手 Artem 是否必胜（输出 `Yes` 或 `No`）。
- **关键约束**：
  - 测试用例数 $t$ 满足 $1 \le t \le 10^4$
  - 单个正整数 $x$ 满足 $1 \le x \le 10^{18}$
  - 时间限制 1.0s，空间限制 256MB

例如：
- $x = 1$ 时，因数集合为 $\{1\}$（奇数），Artem 第一步拿走 $1$，后手无偶数可拿判负，输出 `Yes`；
- $x = 2$ 时，因数集合为 $\{1, 2\}$（一奇一偶），Artem 无论先拿奇还是偶，后手必然能拿走剩下的一张对应奇偶性的牌导致 Artem 无牌可拿，输出 `No`；
- $x = 6$ 时，因数集合为 $\{1, 2, 3, 6\}$（两奇两偶），后手总能镜像回应，Artem 必败，输出 `No`。

## 思路与推导

### 1. 从卡片数值到奇偶二元状态

虽然题目中卡片写有具体的约数值，但游戏规则中对后续操作的唯一限制仅为**卡片的奇偶性交替**。也就是说：
- 卡片的具体数值大小完全不影响游戏进程，一张卡片在博弈中只扮演“奇数”或“偶数”的二元属性；
- 设 $x$ 的所有正因数中，奇因数数量为 $O$（Odd），偶因数数量为 $E$（Even）。

### 2. 对称博弈与最优选择策略

游戏必然从 Artem 选定第一个卡片的奇偶性开始：
- **若 Artem 首选奇数**：
  - 抽牌序列必须为：奇 $\rightarrow$ 偶 $\rightarrow$ 奇 $\rightarrow$ 偶 $\dots$
  - Artem 在第 $1, 3, 5, \dots$ 步消耗奇数牌；后手在第 $2, 4, 6, \dots$ 步消耗偶数牌。
  - 只要 $O > E$，第 $E$ 张偶数牌被后手使用后，Artem 仍能打出第 $E+1$ 张奇数牌。随后轮到后手时已无偶数可用，后手落败，**Artem 必胜**。
- **若 Artem 首选偶数**：
  - 抽牌序列必须为：偶 $\rightarrow$ 奇 $\rightarrow$ 偶 $\rightarrow$ 奇 $\dots$
  - Artem 消耗偶数牌，后手消耗奇数牌。
  - 只要 $E > O$，第 $O$ 张奇数牌被后手使用后，Artem 仍能打出第 $O+1$ 张偶数牌，后手无奇数可用落败，**Artem 必胜**。
- **若 $O = E$**：
  - Artem 首选奇数，后手就用偶数紧跟；Artem 首选偶数，后手就用奇数紧跟。
  - 无论 Artem 作何选择，在进行了 $2O$ 步之后，对应的两类卡片全部被耗尽。第 $2O+1$ 步轮到 Artem 时必定无合法卡片可拿，**Artem 必败**。

因此，博弈的核心胜负手判定极为纯粹：
$$\text{Artem 获胜} \iff O \ne E$$

### 3. 因数分解与奇偶数量关系

既然判定条件是 $O \ne E$，我们考察正整数 $x$ 的因数结构。将 $x$ 写为唯一质因数分解形式：
$$x = 2^k \cdot m \quad (k \ge 0,\; m \text{ 为奇数})$$

对于 $x$ 的任意正因数 $d$，它必然由 $2$ 的若干次幂与 $m$ 的某个因数相乘构成：
- **奇因数**：不能含有质因子 $2$，即 $2$ 的幂次必须为 $0$。因此 $x$ 的所有奇因数恰好就是 $m$ 的所有正因数，$O = \tau(m)$（$\tau$ 表示因数个数函数）。
- **偶因数**：含有至少一个质因子 $2$。其质因子 $2$ 的幂次可以从 $\{1, 2, \dots, k\}$ 中任选（共 $k$ 种可能），而后半部分的奇因数部分仍可从 $m$ 的所有因数中任意选取（共 $O$ 种可能）。

根据乘法原理，偶因数的总数量严格满足：
$$E = k \cdot O$$

由 $O \ge 1$（因为 $1$ 必然是任何正整数的奇因数），我们可以对 $k$ 的取值进行分类：
1. $k = 0$（$x$ 是奇数）：$E = 0 \cdot O = 0$。此时 $O > E = 0$，Artem 必胜；
2. $k = 1$（$x$ 恰好含有一个因子 $2$，即 $x = 2 \times \text{奇数}$，亦即 $x \equiv 2 \pmod 4$）：此时 $E = 1 \cdot O = O$。奇偶因数数量完全相等，**Artem 必败**；
3. $k \ge 2$（$x$ 能被 $4$ 整除）：此时 $E = k \cdot O \ge 2O > O$。偶因数数量多于奇因数，Artem 必胜。

综上所述，原本看似需要大数分解求约数的问题，最终被极其优雅地化简为一个模 $4$ 的常数级运算：
$$\text{Artem 必败 (No)} \iff x \equiv 2 \pmod 4$$
其余所有情况 Artem 均必胜（输出 `Yes`）。

## 代码与复杂度

```python
import sys

def solve():
    # 快速读入所有数据
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    t = int(input_data[0])
    results = []

    for i in range(1, t + 1):
        x = int(input_data[i])
        # 当且仅当 x % 4 == 2 时，x 的偶因数个数与奇因数个数完全相等 (E = O)
        # 此时后手拥有完备的镜像应对策略，先手 Artem 必败
        if x % 4 == 2:
            results.append("No")
        else:
            results.append("Yes")

    # 批量输出结果
    sys.stdout.write("\n".join(results) + "\n")

if __name__ == "__main__":
    solve()
```

- **时间复杂度**：每个测试用例仅执行一次求模运算 `x % 4`，单组用例时间复杂度为 $O(1)$。对于 $t \le 10^4$ 个用例，总时间复杂度为 $O(t)$，耗时在数毫秒内。
- **空间复杂度**：由于直接读入 token 列表并存储结果串输出，辅助空间复杂度为 $O(t)$。

## 本次复盘

1. **题意概念辨析**：
   - 看到题目涉及因数时，第一反应容易联想到“公约数”。但公约数必须建立在两个或多个整数的基底之上；本题输入仅有一个整数 $x$，集合中盛放的是 **$x$ 自身的所有正因数**（包含 $1$ 与 $x$ 本身）。理清这一点是后续数论建模的前提。
2. **状态抽象降维**：
   - 面对 $x \le 10^{18}$ 的大数规模，如果在因数生成或动态规划搜索上下功夫，必然会陷入质因数分解或大数约数计数的性能陷阱。
   - 敏锐捕捉到规则中“**后续每回合奇偶相反**”这一唯一约束，即可将卡片具体数值降维成“奇牌”与“偶牌”两个资源池，博弈胜负瞬间退化为两类牌的数量对比（$O \ne E$ vs $O = E$）。
3. **质因数 2 的倍数关系**：
   - 通过质因数分解 $x = 2^k \cdot m$，发现每一个奇因数与偶因数之间存在天然的 $1 : k$ 映射关系（$E = k \cdot O$）。这一结论直接免除了繁琐的试除求因数过程，将博弈问题瞬间收束为一行 `x % 4 == 2`。
