## 题目与关键约束

- **平台与题目**：Codeforces [B. Problem from Chebarkul]
- **输入输出**：给定一个包含 $n$ 个整数的数组 $a = [a_1, a_2, \dots, a_n]$ 和一个整数 $k$。求有多少个位置 $i$（$1 \le i \le k$），满足在数组 $a$ 的**所有**长度为 $k$ 的子序列中，第 $i$ 个位置上的元素恒为同一个数值。
- **关键约束**：
  - 测试用例数 $t$（$1 \le t \le 10^4$）；
  - $1 \le k \le n \le 2 \cdot 10^5$，所有用例中 $n$ 的总和不超过 $2 \cdot 10^5$；
  - 数组元素 $1 \le a_i \le n$；
  - 时间限制：1.0 秒。

以输入 $a = [1, 2, 2, 2, 5], k = 3$ 为例，所有长度为 3 的子序列中，第 2 个位置（中间位置）无论如何选都必然是 2，而第 1 和第 3 个位置会有变动，因此满足条件的位置数为 1。

## 思路与推导

面对“所有子序列”这类看似存在组合爆炸的题目，最关键的破局点是**从子序列的局部位置去倒推原数组的下标取值范围**。

### 1. 子序列第 $i$ 个位置的下标范围

设我们选出的长度为 $k$ 的子序列在原数组中的下标依次为 $p_1 < p_2 < \dots < p_i < \dots < p_k$：
- 对于第 $i$ 个位置 $p_i$：
  - 前面必须预留至少 $i - 1$ 个元素，因此其最小下标为 $p_i \ge 1 + (i - 1) = i$；
  - 后面必须预留至少 $k - i$ 个元素，因此其最大下标为 $p_i \le n - (k - i) = n - k + i$。

由此可以得到一个确定性结论：
> 长度为 $k$ 的子序列中，其第 $i$ 个位置能够取得的数值集合，**恰好完整覆盖了原数组闭区间 $a[i \dots n - k + i]$ 中的每一个元素**。

### 2. “恒为同一个数”的充要条件

既然第 $i$ 个位置可以任意挑到该闭区间里的任何一个数字，那么要让所有可能选法得到的第 $i$ 个数绝对相同：
- 该区间内**不能存在任何两个不相同的元素**；
- 换句话说，**原数组在区间 $a[i \dots n - k + i]$ 内的所有连续数字必须全部相等**。

观察这个区间的固定长度：
$$L = (n - k + i) - i + 1 = n - k + 1$$
对应 $i = 1, 2, \dots, k$，原数组中正好存在 $k$ 个长度为 $L$ 的滑动窗口。问题转化为：
> **原数组中共有多少个长度为 $L$ 的连续子区间，其内部元素全部相等？**

### 3. 连续相同段（Run-Length）线性统计

一个长度为 $L$ 的连续区间内元素全部相同，当且仅当该区间**完整包含在原数组的某一个连续相同数字块内部**。
因此我们只需将原数组按连续相等关系划分为若干个连续段：
- 设某一连续段的长度为 $cnt$：
  - 若 $cnt \ge L$，该连续段内部可容纳的长度为 $L$ 的子区间数为 $cnt - L + 1$；
  - 若 $cnt < L$，则无法容纳任何长度为 $L$ 的区间，贡献为 0。
- 最终答案即为所有连续段贡献的总和：$\sum \max(0, cnt - L + 1)$。

## 代码与复杂度

```python
import sys

def solve():
    # 针对大规模用例采用快速输入
    input = sys.stdin.read
    data = input().split()
    if not data:
        return

    t = int(data[0])
    idx = 1
    out = []

    for _ in range(t):
        n = int(data[idx])
        k = int(data[idx + 1])
        idx += 2

        a = [int(x) for x in data[idx : idx + n]]
        idx += n

        # 每个子序列位置对应的原数组取值窗口长度是固定的
        L = n - k + 1

        ans = 0
        cnt = 1

        # 线性统计每个连续相同数字块的长度
        for i in range(1, n):
            if a[i] == a[i - 1]:
                cnt += 1
            else:
                if cnt >= L:
                    ans += cnt - L + 1
                cnt = 1

        # 结算最后一个连续块
        if cnt >= L:
            ans += cnt - L + 1

        out.append(str(ans))

    print("\n".join(out))

if __name__ == '__main__':
    solve()
```

- **时间复杂度**：$O(n)$。每个测试用例只对数组进行单次线性扫描，所有测试用例的 $n$ 总和不超过 $2 \cdot 10^5$，总执行时间在 0.1 秒内。
- **空间复杂度**：$O(n)$。用于线性存储输入的数组及输出缓存。

## 本次复盘

1. **思维破局：从全称量词到局部下标区间**：
   - 面对“所有子序列”的题面表述时，避免陷入暴力搜索或复杂 DP 的误区；
   - 核心决策是利用子序列单调性约束，精准推导出第 $i$ 个元素的紧致取值范围 $[i, n - k + i]$。
2. **概念甄别：区间全同 vs 区间有相同元素**：
   - 讨论中曾出现“区间内是否存在相同元素”的模糊直觉；
   - 通过反例明确了：只要区间存在任意不同数值（如 $[2, 3, 2]$），就能挑出不同的子序列导致位置值不唯一，因而必须严格要求**整个长度为 $L$ 的窗口内部所有数值全同**。
3. **计数模型降维**：
   - 识别出每个全同窗口必须完全落入一个连续相等块中，用简单的分组求和公式 $\max(0, cnt - L + 1)$ 将 $O(n^2)$ 的窗口扫描彻底降维为 $O(n)$ 的分块计数。
