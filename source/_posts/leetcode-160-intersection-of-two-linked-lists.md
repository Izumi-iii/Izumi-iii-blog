## 题目与关键约束

- **平台与题号**：LeetCode [160. 相交链表](https://leetcode.cn/problems/intersection-of-two-linked-lists/)
- **输入输出**：给你两个单链表的头节点 `headA` 和 `headB`，请找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `None`。
- **关键约束**：
  - 链表节点数范围 `[0, 3 * 10^4]`（包含空链表情况）；
  - 节点值范围 `[1, 10^5]`；
  - 整个链式结构中不存在环，且函数返回后必须保持两条链表的原有结构；
  - **相交定义**：相交指的是两个链表共享同一个节点对象（即内存地址相同 `pA == pB`），而非仅仅节点值 `.val` 相等；
  - **进阶要求**：能否设计一个时间复杂度 `O(m + n)`、空间复杂度 `O(1)` 的解决方案？

## 思路与推导

### 1. 基础稳健方案：哈希集合查重

如果不限制额外空间，最直观的做法是使用集合 `visited = set()`：
- 先完整遍历链表 A，将所有节点对象本身（注意：存 `curr` 而非 `curr.val`）存入集合；
- 再遍历链表 B，第一个出现在 `visited` 中的节点便是相交起点；
- 该方案时间复杂度 `O(m + n)`，空间复杂度 `O(m)`。

### 2. 进阶 `O(1)` 空间解法：双指针“走过你来时的路”

直接让 `pA` 和 `pB` 从两个头节点同步前进，之所以会错过交点，是因为两条链表在相交前的**前缀长度不相等**。
设链表 A 独有前缀长为 `a`，链表 B 独有前缀长为 `b`，相交后的公共尾部长度为 `c`：

```text
链表 A: [  a  ] + [  c  ]
链表 B: [     b     ] + [  c  ]
```

如果让两个指针走完自己的链表后，**立刻跳转到对方的头节点继续走**：
- `pA` 走过的总步数：`a + c + b`
- `pB` 走过的总步数：`b + c + a`

由于 `a + c + b == b + c + a`，无论前缀长度差多少，两位跑者走过完全相同的总路程，**必然在交点处同时相遇**！

### 3. 边界防御：不相交时为什么不会死循环？
如果两条链表压根不相交（`c = 0`）：
- `pA` 走完 A 再走完 B，一共走了 `a + b` 步后踏上 `None`；
- `pB` 走完 B 再走完 A，一共走了 `b + a` 步后也在同一时刻踏上 `None`；
- 此时满足 `pA == pB`（两者均为 `None`），循环 `while pA != pB:` 自动终止并返回 `None`。

**编码避坑关键**：判断指针跳转时**必须写 `if pA:`**（让指针亲自踩一脚 `None` 后再切换至 `headB`），而绝不能写 `if pA.next:`（否则在不相交时会直接绕过 `None` 进入对方头部，导致死循环）。

## 代码与复杂度

以下为本次练习最终独立编写完成并经全边界静态验证的 `O(1)` 空间双指针实现：

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        pA = headA
        pB = headB

        # 当双方在交点相遇，或不相交同时抵达 None 时循环退出
        while pA != pB:
            # 必须先走一步踩上 None，下一轮再切换至对方头节点，避免不相交时死循环
            if pA:
                pA = pA.next
            else:
                pA = headB

            if pB:
                pB = pB.next
            else:
                pB = headA

        return pA
```

- **时间复杂度**：`O(m + n)`，其中 `m` 与 `n` 分别为两条链表的长度。两个指针最多各自走完两条链表的长度总和。
- **空间复杂度**：`O(1)`。仅使用了常数个指针变量 `pA`、`pB`，达到题目进阶最优标准。
