删除链表倒数第 N 个结点，难点是单链表只能从前往后走，无法直接从尾部定位。快慢指针先拉开固定间距，再同步前进，就能让慢指针停在待删除结点的前一个位置。

<!-- more -->

## 题目与关键约束

LeetCode 19 给定链表头结点 `head` 和整数 `n`，删除链表倒数第 `n` 个结点，并返回新链表头。需要考虑删除原头结点的情况，因此使用虚拟头结点统一处理。

## 思路与推导

创建 `dummy`，令它指向原链表：

```text
dummy → 1 → 2 → 3 → 4 → 5
```

令快慢指针都从 `dummy` 出发。快指针先走 `n + 1` 步，让两指针之间隔着待删除结点以及它前面的结点。随后二者同步向后，直到快指针到达 `None`。此时慢指针停在目标结点的前驱，执行 `slow.next = slow.next.next` 即可删除它。

以链表 `1 → 2 → 3 → 4 → 5`、`n = 2` 为例：快指针先走三步到结点 3；之后两指针同步前进，快指针从 3 走到 5，再走到 `None`，慢指针停在结点 3。跳过它的下一个结点 4，得到 `1 → 2 → 3 → 5`。

为什么要先走 `n + 1` 步？因为慢指针需要落在待删除结点的前一个位置。若只拉开 `n` 步并以快指针到达 `None` 为停止条件，慢指针会停在待删除结点本身，无法直接改它的前驱链接。

当删除的是原头结点时，慢指针会停在 `dummy`，相同的跳接操作仍然成立。最终返回 `dummy.next`，可覆盖头结点被删除的情况。

## 代码与复杂度

```python
# LeetCode 提供 ListNode 定义
class Solution:
    def removeNthFromEnd(self, head: ListNode | None, n: int) -> ListNode | None:
        dummy = ListNode(0, head)
        slow = dummy
        fast = dummy

        for _ in range(n + 1):
            fast = fast.next

        while fast is not None:
            slow = slow.next
            fast = fast.next

        slow.next = slow.next.next
        return dummy.next
```

设链表长度为 L，快慢指针总共最多经过 L 个结点，时间复杂度为 O(L)，额外空间复杂度为 O(1)。练习中用户反馈“通过”；文章代码采用从虚拟头结点出发并先走 `n + 1` 步的版本，与推导一致。

## 本次复盘

原先的思路是快指针先走 n 步，再同时移动；关键是要明确慢指针应停在待删除结点的前驱，而不是目标结点。加上虚拟头结点后，删除头结点也不用单独分支处理。

实现时还需留意指针初始化：应写 `slow = dummy`、`fast = dummy`，而不是给尚未创建的指针设置 `.next`。此外，空链表检查若直接访问 `head.next` 会出错；虚拟头结点配合题目保证的有效 n，可以自然覆盖单节点和删除头结点的情形。

下次处理链表删除，可以先问自己：要修改目标结点，是否需要停在它的前驱？若是，虚拟头结点通常能消除头部特判。
