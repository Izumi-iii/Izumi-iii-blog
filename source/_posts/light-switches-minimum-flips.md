## 题目与关键约束

- **问题背景**：有一排 $n$ 盏灯，初始状态用 01 字符串表示（`0` 代表熄灭，`1` 代表点亮）。
- **操作规则**：
  - 选择第 `i` 盏灯的开关，会同时翻转第 `i`、`i+1`、`i+2` 盏灯的状态（亮变灭，灭变亮）；
  - 最右边不足三盏时超出范围则忽略，只翻转实际存在的灯；
  - 每个开关最多按一次（按两次等价于未按）。
- **求解目标**：求将所有灯全部点亮所需的最少操作次数。

以输入 `"000"` 为例，按下开关 0 后，第 0、1、2 盏灯全部由 0 翻转为 1，最少操作 1 次即可完成全亮。

## 思路与推导

看似每个开关能波及三个位置、状态错综复杂，但本题具有极强的**局部确定性（无后效性）**。

### 1. 操作的两个基本定理
- **操作顺序无关**：先按开关 A 再按开关 B，与先按 B 再按 A 产生的最终状态完全相同；
- **状态二值性**：每个开关按两次等于没按，因此对每个开关只需决定“按（1次）”或“不按（0次）”。

### 2. 唯一的救星：从左至右锁定决策
我们观察各个开关能够波及的范围：
- 开关 0：影响 `0, 1, 2`；
- 开关 1：影响 `1, 2, 3`；
- 开关 2：影响 `2, 3, 4`；
- ……
- 开关 `i`：影响 `i, i+1, i+2`。

由此可得出决定性的结论：
1. **对于第 0 盏灯**：除了开关 0 之外，后续所有的开关（1, 2, 3...）在物理上**永远无法触及第 0 盏灯**。
   - 若灯 0 初始为灭（0），开关 0 是点亮它的**唯一手段**，必须按下；
   - 若灯 0 初始为亮（1），则绝对不能按开关 0。
2. **状态锁定向右递推**：当处理到第 `i` 盏灯时，左侧 `0 ~ i-1` 位的灯已经全部为亮且不可再被更动。
   - 右侧的所有开关 `i+1, i+2...` 无法影响到灯 `i`；
   - 因此，**开关 `i` 按不按，完全且唯一地取决于当前灯 `i` 的状态**：灯 `i` 为灭则必按，为亮则绝不按。

这使得整道题完全退化为从左至右单向扫描的确定性贪心模拟。

## 代码与复杂度

```python
class Solution:
    def minOperations(self, s: str) -> int:
        # 将不可变字符串转为整数列表，支持原地状态反转
        lights = [int(ch) for ch in s]
        n = len(lights)
        ans = 0

        # 从左到右贪心遍历，每个开关决策具有唯一确定性
        for i in range(n):
            # 当前灯为灭，开关 i 是点亮它的唯一机会，必须按
            if lights[i] == 0:
                lights[i] = 1 - lights[i]

                # 翻转后续联动的灯（若超出右侧边界则安全忽略）
                if i + 1 < n:
                    lights[i + 1] = 1 - lights[i + 1]
                if i + 2 < n:
                    lights[i + 2] = 1 - lights[i + 2]

                ans += 1

        return ans
```

- **时间复杂度**：`O(n)`。仅需对长度为 `n` 的序列进行单向线性扫描，每个位置翻转操作为常数级别 `O(1)`。
- **空间复杂度**：`O(n)`。转换生成的列表存储开销为 `O(n)`（若输入直接为可变列表则可达到 `O(1)` 额外空间）。

## 本次复盘

1. **贪心无后效性的提炼**：初读题目容易陷入类似指数级搜索的误区。通过从最左端单向切入，抓住“后续开关无法反向影响前缀”的不变性，迅速将问题转化为线性贪心决策。
2. **末尾边界保护**：在循环末尾两项，`i + 1` 和 `i + 2` 会超出数组范围。结合题面中“最右边凑不满三盏时，就只翻还存在的”规则，必须显式附加 `if i + 1 < n` 与 `if i + 2 < n` 条件校验，防止抛出 `IndexError`。
3. **数据结构可变性**：在 Python 中字符串为不可变对象，无法通过 `s[i] = ...` 进行原地置换，通过列表推导 `[int(ch) for ch in s]` 进行预转换是避免类型报错的标准做法。
