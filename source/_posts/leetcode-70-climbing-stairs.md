## 题目与关键约束

- **平台与题号**：LeetCode [70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/)
- **输入输出**：假设你正在爬楼梯，需要 `n` 阶才能到达楼顶。每次你可以爬 `1` 或 `2` 个台阶。计算有多少种不同的方法可以爬到楼顶。
- **关键约束**：
  - `1 <= n <= 45`（输入为正整数，需留意 `n = 1` 与 `n = 2` 时的数组初始化边界）。

例如输入 `n = 3`，共有 3 种方法爬到楼顶：`1+1+1`、`1+2`、`2+1`。

## 思路与推导

本题是理解**动态规划（Dynamic Programming）**思想的入门第一题。

### 1. 逆向思考：抓住“最后一步”
定义状态 `dp[i]` 表示“爬到第 `i` 阶台阶一共有多少种不同的方法”。

设想我们已经到达终点第 `n` 阶，因为题目限制每次只能跨 `1` 阶或 `2` 阶，那么在迈出最后一步之前，我们只有两种可能的位置来源：
- **从第 `n - 1` 阶出发**：跨 1 阶到达终点，共有 `dp[n - 1]` 种路径；
- **从第 `n - 2` 阶出发**：跨 2 步到达终点，共有 `dp[n - 2]` 种路径。

由于最后一步的动作完全互斥（一个是跨 1 步，一个是跨 2 步），且穷尽了所有到达第 `n` 阶的方案，因此得到状态转移方程：
`dp[n] = dp[n - 1] + dp[n - 2]`

### 2. 初始条件与边界防御
要推动上述递推式计算，需先确认最小的初始起点：
- `dp[1] = 1`（爬到第 1 阶只有 1 种方法）
- `dp[2] = 2`（爬到第 2 阶有 `1+1` 和 `2` 共 2 种方法）

若直接创建长度为 `n + 1` 的数组并赋值 `dp[2] = 2`，在输入 `n = 1` 时，列表最大下标仅为 1，会导致 `IndexError` 越界报错。因此先使用 `if n < 3: return n` 提前拦截处理。

### 3. 面试空间优化：滚动变量
观察转移方程 `dp[i] = dp[i - 1] + dp[i - 2]` 可发现：计算当前台阶时，只依赖前两项的状态，更早计算过的 `dp[0] ... dp[i - 3]` 之后再也不会被用到。
因此无需维护整个长度为 `n + 1` 的数组，只需用两个变量 `a, b = 1, 2` 不断执行 `a, b = b, a + b` 滚动向前，即可将空间复杂度从 `O(n)` 压缩至 `O(1)`。

## 代码与复杂度

以下为本次练习独立编写完成的标准一维 DP 实现（已通过静态边界与逻辑核对）：

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # 边界特判：n=1 返回 1，n=2 返回 2，防止后续 dp[2] 越界
        if n < 3:
            return n

        # dp[i] 表示到达第 i 阶台阶的总方法数
        dp = [0] * (n + 1)
        dp[1] = 1
        dp[2] = 2

        for i in range(3, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]

        return dp[n]
```

- **时间复杂度**：`O(n)`。单层循环从 `3` 线性推进到 `n`，每步执行常数次加法计算。
- **空间复杂度**：`O(n)`。开辟了长度为 `n + 1` 的列表 `dp` 记录所有状态。*(若用上述滚动变量替代数组，空间复杂度可优化至 `O(1)`)*。
