将两个升序链表合并成一个升序链表，可以每次比较两个链表当前节点，把较小的节点接到结果链表末尾。循环结束后，另一条链表剩余的部分已经有序，可以整体接上。

## 题目与关键约束

LeetCode 21「合并两个有序链表」给定两个升序单链表 `list1` 和 `list2`，将它们合并为一个升序链表并返回头结点。可以复用输入链表的节点，无需新建所有节点；使用虚拟头结点能避免对结果头部单独处理。

## 思路与推导

设 `p1`、`p2` 分别指向两条链表尚未处理的首节点，`p` 指向合并结果的末尾。每轮比较 `p1.val` 和 `p2.val`，把较小的节点接到 `p.next`，并推进对应的输入指针。接入节点后，`p` 也要跟着移动到新末尾。

例如合并 `1 → 3` 与 `2 → 4`：

- 比较 1 和 2，接入 1。
- 比较 3 和 2，接入 2。
- 比较 3 和 4，接入 3。
- 第一条链表耗尽，把剩余的 `4` 接上。

当某条链表耗尽时，另一条链表剩余部分不需要逐个比较，因为它本身已经有序，且其中所有值都不小于已接入的节点。因此可以直接接到结果尾部。

虚拟头结点 `dummy` 只负责固定结果链表的起点，返回 `dummy.next` 即可。若其中一条链表为空，主循环不会运行，最后会把另一条链表直接接上，所以也自然处理空链表情况。

## 代码与复杂度

```python
# LeetCode 提供 ListNode 定义
class Solution:
    def mergeTwoLists(self, list1: ListNode | None, list2: ListNode | None) -> ListNode | None:
        p1, p2 = list1, list2
        dummy = ListNode(0)
        p = dummy

        while p1 is not None and p2 is not None:
            if p1.val <= p2.val:
                p.next = p1
                p1 = p1.next
            else:
                p.next = p2
                p2 = p2.next

            p = p.next

        p.next = p1 if p1 is not None else p2
        return dummy.next
```

设两个链表长度分别为 m、n。每个节点最多处理一次，时间复杂度为 O(m + n)；复用原节点，额外空间复杂度为 O(1)。

练习中用户反馈“通过”。用户代码的主体逻辑正确，审阅时发现合并循环缺少 `p = p.next`：若 `p` 一直停在虚拟头结点，每轮都会覆盖 `dummy.next`，无法逐步构造结果链表。

## 本次复盘

关键状态是三个指针：`p1` 和 `p2` 表示两条输入链表的当前位置，`p` 表示结果链表末尾。每次接入一个节点后，必须同时推进被选中的输入指针和结果尾指针。

下次写“逐个取较小值”的合并过程，可以逐轮确认：接了哪个节点、哪条输入链表前进、结果尾指针是否也前进。循环退出时，再利用输入链表已有的有序性整体接上剩余部分。
